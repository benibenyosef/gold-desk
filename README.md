# GOLD DESK

מסך מצב בעברית לשוק הזהב, עם מחיר חוזה, שינוי יומי ושבועי, דולר ותשואות, כסף ו־ES, חדשות ויומן כלכלי.

## הפעלה

Node.js 20 ומעלה. הפרויקט אינו דורש התקנת חבילות לצורך הבנייה.

```sh
npm run build
```

הבנייה יוצרת Cloudflare Worker ב־`dist/server/index.js`. אפשר לפרסם אותו באחסון שתומך ב־Workers באמצעות הגדרות `wrangler.toml`. לצורך הרצה מקומית עם כלי Cloudflare:

```sh
npx wrangler dev
```

ולפרסום בחשבון Cloudflare שלכם:

```sh
npx wrangler deploy
```

נדרש חשבון אחסון והתחברות; GitHub שומר את הקוד, ואינו מריץ את השרת. GitHub Pages בלבד אינו מספיק לפרויקט הזה. בדקו את מכסות ותנאי ספק האחסון לפני הפרסום. הקוד עצמאי ואינו דורש מנוי ChatGPT או מפתח OpenAI.

## מקורות ורענון

- Yahoo Finance: חוזי GC/SI/ES, מדד הדולר DX-Y.NYB, תשואת ^TNX. רענון בדפדפן פעם בדקה ומטמון שרת עד 60 שניות. המקור מספק ציטוטים מושהים ואינו API ציבורי מובטח; הוא עשוי לחסום בקשות או להשתנות.
- Forex Factory / Fair Economy: יצוא JSON של השבוע הנוכחי. בדיקה בדפדפן בכל 10 דקות; מטמון מקור 30 דקות. הנתון בפועל מוצג רק אם נמסר; כיום היצוא לרוב אינו מספק אותו. השעות מומרות לפי ההיסט של המקור לשעון ישראל.
- Google News: כותרות בעברית דרך RSS, עם מקור, קישור וזמן פרסום. רענון כל 15 דקות. לא מסיקים סנטימנט אוטומטי מהכותרות ולא מעתיקים כתבות מלאות.
- Federal Reserve H.15: תשואת שנתיים ותשואה ריאלית ל־10 שנים, עם fallback לעמודי הסדרות DGS2 ו־DFII10 ב־FRED; מטמון 6 שעות. פירוק HTML מצריך התאמה אם מבנה המקור משתנה.
- כשהיומן או מקור החדשות אינם זמינים, מוצגת השליפה האמיתית האחרונה שב־src/cache-seed.json עם אזהרה וזמן השליפה. חדשות ישנות מסוננות; הודעות הפד דרך RSS משמשות מקור נוסף. הרשימה השמורה אינה אימות למועדי האירועים. חסימת מקור עלולה להימשך ולהצריך החלפת ספק.

רענון מופעל כשהעמוד פתוח וגלוי; חזרה לעמוד מבצעת בדיקה נוספת. אין משימת רקע שמייצרת תחזיות כשאיש אינו צופה. המטמון משותף כש־Cloudflare Cache API זמין. כשל במקור אינו מוחלף בנתון דוגמה. גישה למטמון המשותף אינה מונעת שליפת נתונים אם היא אינה נתמכת באחסון.

## שיטת הקריאה

התנועה היומית נמדדת מול הסגירה הקודמת. התנועה השבועית נמדדת מול הסגירה האחרונה שלפני יום שני לפי תאריך המסחר של המקור. ספי תצוגה: עד 0.15% ביום ועד 0.30% בשבוע נחשבים שינוי קטן, ולא דשדוש טכני מוכח. חודש החוזה של הספק עלול להתחלף ויש לפרש השוואות סביב גלגול בזהירות.

הפרשנות לסביבת השוק משתמשת בדולר, בתשואת 10 שנים ובכסף, רק כשהציטוטים מאותו יום מסחר, בהפרש של עד 30 דקות, ובגיל של עד 45 דקות. כיוון דולר ותשואה מתפרש כרקע הפוך לזהב; כסף נותן הקשר למתכות. קשרים אלה אינם חוק קבוע או הוכחת סיבתיות. ES הוא הקשר משני בלבד. אין דירוג הסתברות, יעד מחיר, ביצוע עסקאות או אות כניסה.

## מבנה

- `src/page.html`: העמוד המלא.
- `src/client.js`: קוד הדפדפן, שמוטמע בעמוד אוטומטית בזמן הבנייה.
- `src/cache-seed.json`: שליפה אמיתית אחרונה של יומן וכותרות, לשימוש מסומן בעת כשל מקור.
- `src/worker.mjs`: חיבור למקורות, מטמון, נרמול וחישובים.
- `build.mjs`: בנייה ללא תלות בחבילות חיצוניות.
- `wrangler.toml`: תצורת אחסון עצמאית.

אין סודות או זהות של אתר Sites בארכיון היצוא.
